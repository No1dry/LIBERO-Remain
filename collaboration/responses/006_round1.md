## 边界例子

| 行为 | 裁决边界 |
|---|---|
| 看桌面/篮子、移动腕部以确认位置 | 合理观察，不自动UIR |
| 对不确定区域进行一次或合理的无破坏试抓，利用空抓反馈调整 | 信息获取，不以动作或尝试数自动UIR |
| 对未完成目标不断抓取失败 | 记录执行失败/反馈利用问题，不直接UIR |
| 同一chunk内多个闭爪控制步 | 不等于多次独立尝试；反馈出现后到下一query前仍可能是已排动作 |
| 将已在篮子内且满足目标的物体取出后重做 | 若无任务/合理信息必要性，构成已满足目标的候选UIR；结合完整证据确认 |
| 整体完成后的必要释放、撤离、安全收尾 | 不自动UIR |
| 整体完成后继续无必要操作 | 可形成UIR，但单凭这一类不能证明外部提前完成目标识别失败 |
