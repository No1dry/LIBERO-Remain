# 完整方法设计v1：带实体证据与可撤销历史的剩余目标选择器

日期：2026-10-21。决策/设计：Codex。状态：完整架构候选，交X做一次集中可实施性审阅；不是实现或真实数据/训练/eval启动授权。

本文件承接[实验结果](2026-10-20_baseline_results.md)、[四路线讨论](2026-10-20_codex_method_proposals.md)与[X第二轮对比](https://github.com/No1dry/LIBERO-Remain/blob/20a172a6a511ff1687a298f48aea6c79c65381d7/collaboration/responses/methods_2026-10-20_round2_comparison.md)。不要求先完成MVP或一组额外诊断才允许设计完整方法。

## 1. 本次选择

主路线为③＋④：**训练一个与VLA解耦的视觉目标/实体判断模块，结合有限证据历史选择当前子目标，再驱动冻结VLA。**

工作描述：Evidence-Grounded Remaining-Goal Selection，简称EGRS。名称仅用于本项目设计讨论，不声明新颖性或优于已有工作。

- 学习的是“这个目标现在是否仍需要操作、对应哪个可见实体、证据是否充分”。
- 不训练连续动作，不微调原VLA及其动作头。
- 记忆维护使用规则；独立选择器实际读取历史。
- 默认只用子目标语言连接VLA，保留原相机图像和原生预处理。
- 当前主实验仍只测冻结任务的mask10；不扩任务、FINISH或顺序依赖研究。

可直接开发这一完整架构。数据、模型、历史、接口与记录作为同一个完整实现交付，而不是先排队跑多个MVP。

## 2. 能力归属与关键限制

### 2.1 对象证据如何影响动作

选择器输出图像中的实体/区域、目标关系与证据，用于：
1. 把语言目标绑定到当前观测中的对象；
2. 判断该对象的目标关系及可见性；
3. 在历史中关联同一对象，检查尝试后的证据变化；
4. 生成来自原任务、与底座语言风格兼容的当前子目标。

例如当前子目标为 `put the tomato sauce in the basket`。可使用经视觉确认、与原任务一致的名称/属性消歧，但不向底座发送未经训练支持的坐标指令。

**这提供的是语义条件化，不是对机械臂的空间硬约束。**只给文本时，正确物体框不会直接限制手的运动。若短指令仍导致抓错，原评分照计失败；不能把选择器定位正确当任务成功。

默认不加bbox标记、图像遮罩、目标crop替换原图、点目标通道、动作shield、世界模型或候选动作重排序。这些是不同接口/更大方法范围，不能暗中加入并仍宣称原样通用冻结。

### 2.2 三层通用性分别报告

- 接口可移植：不同VLA可接收语言子目标。
- 模块可复用：同一个选择器checkpoint与历史规则不因换VLA而重训。
- 效果可迁移：复用后确实改善合规完成或效率。

第一层不是后两层的证据。VLA必须具备相应子任务执行能力；不保证任何VLA都有效。

## 3. 模块与在线数据流

| 模块 | 输入 | 输出 | 是否训练 |
|---|---|---|---|
| 任务/实体证据模块 | 原任务、当前RGB/proprio、有限历史 | 原任务目标、实体区域、关系/释放证据 | 选择器LoRA |
| 证据历史 | 先前查询时观察和预测、当前新证据 | 有时间与来源的短记录，允许撤销 | 规则维护 |
| 目标调度 | 预测证据、当前执行目标、历史 | 保持/切换当前子目标，或原指令回退 | 默认显式规则，不学task ID到B |
| 冻结执行器桥接 | 原RGB/proprio、当前子目标 | VLA原生解码后的7D动作/chunk | 不更新VLA |
| 原评价端 | 真实任务与逐步物理事实 | 既定终点、事件、TCP路径与分数 | 完全独立 |

评价端真值只进入评分文件，不进入选择器、历史或VLA。原完整指令始终保存，评分目标不因当前子目标改变。

## 4. 选择器模型与输出契约

### 4.1 默认模型候选

默认采用独立的 `Qwen/Qwen2.5-VL-3B-Instruct`，训练选择器LoRA；不读取OFT隐层特征。它本身是预训练VLM，因此本方案不是“没有大模型/没有预训练成本”。

选型理由仅为已有多图像、定位和结构化输出接口，并非已验证其LIBERO关系判断有效。官方[模型卡](https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct)提供这些接口说明；模型修订、processor、依赖及许可在实现前固定，不使用浮动latest。

训练初始配置候选：冻结视觉编码器与基础权重，仅训练语言注意力投影LoRA，r=16、alpha=32、bf16、学习率1e-4、全局batch16、最多3个epoch。X可根据官方训练接口提出一次有依据的替代。以上不是已运行配置或显存/耗时保证。

选择器使用独立Python/worker，避免覆盖OFT依赖。候选实现可复用[官方微调代码目录](https://github.com/QwenLM/Qwen3-VL/tree/main/qwen-vl-finetune)中明确兼容Qwen2.5-VL的路径，不能因仓库重命名而误用不兼容结构。

### 4.2 输入

- 原完整任务文本；目标语义由文本提取，不在线查任务编号→目标表。
- 当前agentview与wrist RGB，以及允许的机器人本体观测。
- 最近最多2个已获得查询时刻的图像快照；加当前最多6幅图，不额外render。
- 最多12条紧凑历史记录，包含查询序号、证据来源、短语目标及不确定项。
- 不含task_id、mask、官方谓词、仿真物体ID/坐标、接触真值、未来帧或评价端停止原因。

图像大小/visual-token上限在配置中固定，历史开关不暗中提高原VLA输入分辨率。同一轮比较记录实际图像数和调用量。

### 4.3 结构化输出

示意字段：

```json
{
  "goals": [
    {
      "goal_ref": "g0",
      "goal_text": "put the alphabet soup in the basket",
      "entity": {
        "description": "alphabet soup can",
        "camera": "agentview",
        "bbox_xyxy_normalized": null
      },
      "relation_evidence": "UNKNOWN",
      "release_evidence": "UNKNOWN",
      "evidence_refs": []
    },
    {
      "goal_ref": "g1",
      "goal_text": "put the tomato sauce in the basket",
      "entity": {
        "description": "tomato sauce can",
        "camera": "agentview",
        "bbox_xyxy_normalized": [0.1, 0.2, 0.3, 0.6]
      },
      "relation_evidence": "UNSAT",
      "release_evidence": "UNKNOWN",
      "evidence_refs": ["current:agentview:region"]
    }
  ],
  "interaction_hint": "UNCERTAIN"
}
```

数值框仅为格式示例，不对应真实场景。区域为传感预测，不是仿真object ID；找不到时允许null。SAT/UNSAT/UNKNOWN是对可获得证据的预测，不是物理认证。

关系、释放与携带阶段分开；抽屉/开关不硬套物体释放。场景中对象已在目标容器附近或内部，不足以推断已经松手。输出不包含FINISH或自由生成新任务。

不把模型自报“0.99置信度”当可靠概率。默认使用离散证据状态与明确来源；若实现采用分数，只能作为待校准排名，校准来自dev，不能在线用评测真值修正。

## 5. 调度与历史更新

### 5.1 查询边界

默认每次VLA查询前运行一次选择器，然后调用一次VLA。不增加中间物理步、额外相机视角或隐藏试执行。

当前runner通常每个accepted chunk后才给策略新观测；OFT的cap为8。只能承诺查询边界重规划，不能承诺在step1—7发现并阻止错误。历史也不能编造这些中间时刻的对象事件。

底座输出长chunk时按公开cap截断并记录；不因选择器存在改变基准H520/K4或把丢弃动作计入实际路径。

### 5.2 调度优先级

1. 若已有可信当前目标，且传感证据支持正在持物/搬运，保留该目标，直到有释放证据或身份反证；不因短暂遮挡切回另一目标。
2. 其他情况下优先选有明确UNSAT证据、且属于原任务的目标。已有同目标时尽量保持，减少无证据来回切换。
3. UNKNOWN不等于SAT。可以先执行另一个明确待完成目标，但未知项保留在历史，不能永久删除。
4. 若所有目标都UNKNOWN，或没有可靠待执行目标，且不满足第1项，则回退原完整指令，由原VLA产生合法动作。
5. 所有目标被预测SAT也不向runner返回STOP或零动作；仍遵守第1/4项和原评价端。预测错误、回退导致错抓/回退或未完成时如实失败。

原指令回退只是接口回退，不是安全保持，不能保证保留A。不把模型收到下一次predict调用当作某个具体目标未完成的真值。

目标文本与对象描述必须来自原任务与当前证据。无额外知识时不生成“移走干扰物”“开爪”“退回”之类新动作目标；不能假设原VLA有可靠的“观察”技能。

### 5.3 证据历史

每条记录包含：查询序号、可见对象/区域关联、预测关系、预测携带/释放线索、当前子目标、先前发出的动作摘要与证据来源。

- episode reset时记忆为空，不写入“A已完成”。
- 历史只能来自已获得的观测；原始模型输出的动作是命令，不是已成功执行或抓起物体的证据。
- 历史不读取逐步评价日志，不把双指接触真值或谓词写进在线记录。
- 暂定规则：连续2个查询时刻支持同一SAT证据才提升完成信念；新反证立即撤销；连续3次不可见后降为UNKNOWN。参数在dev固定，不等同于评分K4，也不是已校准最优值。
- “失败了多次”只触发重新判断，不推出目标已完成，也不自动永久跳过。
- 初始从未见过的完成过程，不能靠历史补出来；不确定性要真实保留。
- 记录超限只按固定时间/证据规则压缩，不选择性保留看起来成功的记录。

## 6. 冻结执行器桥接与缓存

底座继续接收原始相机图像与原有proprio处理，唯一默认变化是当前任务文本。选择器判断/框不会作为额外GT或图像标记塞给VLA。

为不同底座声明goal-change能力，不统一调用episode reset：
- OFT本地adapter无跨查询动作队列，目标文本切换可无额外reset。
- UniVLA有latent历史与动作时序聚合，需要专门清除旧目标缓存。
- OpenPI的reset可能重新建立采样RNG，不可在每次目标变化时直接调用它。
- 仅在新episode按原流程重置随机数。目标改变不能额外重新播种或装载权重。

需要的接口概念是 `on_goal_change(old_text, new_text)`，清缓存但保留权重和随机流；实际命名由X确定。无法支持时如实声明，不能用统一全reset假装兼容。

若在外层组合两个SubprocessPolicy，父层只能拿白名单观测；不通过传感字典塞进selector元数据。选择器与底座身份分别记录。

## 7. 训练数据与初始预算

数量为待用户确认的**预算草案**，不是已下载/标注完成或“已经足够”的证据。

### 7.1 来源与数量

- 从官方普通演示中选约20个任务组，每组10个来源episode，总目标200个来源episode。
- 默认不使用当前六个LIBERO-10复合评测任务及其语义等价组合；不新增LIBERO-90训练来掩盖扩展域差异。
- 选取任务需覆盖实际关系类型与对象角色；目前未给出一份已核验的20任务文件清单，由X在一次评阅中确认可获得性与缺口，不能编造数量。
- 每来源最多6个有意义短窗口，最多约1,200窗口；每窗口最多3个合法目标/实体查询，约3,600条query。
- 200来源、1,200窗口、3,600query分别报告，不把派生查询当独立轨迹。
- 这些是既有普通演示的读取/监督预算，不是200次新增VLA rollout，也不包含正确恢复动作采集。
- 物理侧恢复、生成状态标签或新视图即使没有VLA，也须由用户启动。

### 7.2 划分

来源episode及其已知同源/重复初态先成组，按任务分层以约80%/20%划train/dev；相邻帧、后缀、改写、配对和增强继承同一归属。不要求重新完成旧的demo↔official-init逐一映射工程；未知物理祖源如实披露。

当前冻结评测状态、0..9来源及其等价数据不进入训练或dev。已有研究使用历史保留，不能称整个评测集从未暴露。排除完整复合任务可支持目标组合迁移设计，不自动证明未知物体/未知场景泛化。

若改为使用当前被测复合任务训练，必须明确改称目标任务适配；不能悄悄切换数据定义。

### 7.3 物理真值与可见证据分列

每条关系保留：
- `physical_truth`：物理侧关系，仅离线监督/审计可见；
- `visual_evidence`：RGB支持SAT、UNSAT还是UNKNOWN，附时间/相机/区域；
- `evidence_label_source`：人工确认、审阅过的候选、弱标签等。

物理真值为真不能自动生成“图像确认完成”；分割面积或投影可见也不能自动证明包含、接触或释放肉眼可辨。VLM伪标签不是GT。

初始标注预算建议：约600个明确正反证据窗口＋300个遮挡/歧义窗口进行证据标注；余下300个可保留弱标签，未确认可辨性时屏蔽可见状态损失。标注是一次性训练成本，不要求用户逐条审核全部eval视频；人员/离线候选生成方式和实际工作量在启动前确认。没有标注资源不能把弱标签宣称为已人工确认。

### 7.4 角色与配对

同一物体在合法查询中分别作为任务对象、已有完成证据对象或普通干扰物；同一场景可提出不同关系查询，必须逐条重新确定标签。

前后关系变化、明确视图与遮挡视图可形成同组配对。它们监督对象身份、目标关系和证据变化，不要求正确动作，也不要求避障动作保持不变。优先复用已有真实状态，不在本阶段强制另造大规模反事实环境。

## 8. 训练目标与冻结范围

采用结构化SFT：
- 实体引用/可见区域；
- 逐目标关系与释放证据；
- 短的可核对证据引用。

默认先训练这些判断，目标调度按第5节规则消费其输出，不训练任务编号→固定下一目标。若加入选择监督，多个允许目标用集合/掩码监督，不强制唯一A/B答案。

输出token交叉熵按实体/状态/证据字段分段记录；未确认可辨性的状态字段不计硬标签损失。配对与角色负例作为监督样本进入，不把复杂对比损失设为必需。训练历史严格来自当前帧以前，不使用教师未来观测。

LoRA可训练参数只属于选择器；VLA、动作头、proprio projector及底座归一化不更新。训练期间不调用VLA获取伪正确动作。

## 9. 运行、故障与实验记录

- 完整方法身份单独版本化：selector base/LoRA/processor、历史规则、文本构造、底座checkpoint/adapter、实际输入文本与cap。
- 不伪装成原始plain SOG10模型绕过旧实验专有校验；复用或显式扩展通用驱动，原批次身份不改。
- 决策正常UNKNOWN可按明确定义回退；模型加载、通信、非法schema等硬错误记技术故障，保留partial，不悄悄退回baseline后声称新方法执行成功。
- 原冻结状态、原评分、双相机视频、逐步动作/路径证据保持。selector预测和在线记忆另存，不能伪装为物理事实。
- 记录selector调用、底座调用、图像数、训练/推理时间及回退原因；不把额外计算写成免费能力。
- 不静默重试或增加真实episode，不热改运行目录。

## 10. 完整方法的比较结构

这是后续评估结构，不是实现前必须跑完的阶梯：

1. 原始冻结VLA＋原完整指令：已有基线。
2. 完整EGRS。
3. 同一selector base但不加载任务LoRA，使用相同历史与文本接口：①＋④对照。
4. 训练后的选择器去历史、去角色负例/绑定监督：必要机制消融。
5. ②普通动作微调为数据充分时可选强比较，不设为必选前提。
6. 换底座时先保持同一selector与历史规则，不按新底座重新挑训练样本后仍声称直接迁移。

不新增主metric：合规成功率与成功条件TCP路径。实体绑定、可见状态三分类、错误确认完成、unknown和回退等仅作诊断；dev判断不使用评测结果挑规则。选择器准确而行为无改善，视为文本/执行接口的真实上限，不掩盖失败。
